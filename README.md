# ⚡ EV Dock Website

EV Dock is a modern and responsive **Electric Vehicle (EV) Charging Platform Website** built to showcase EV charging solutions, charging infrastructure, hardware, software, mobile applications, and business partnership opportunities.

The website is designed with a premium, modern UI focused on **performance, responsiveness, scalability, and user experience**.

---

## 🚀 About EV Dock

EV Dock provides a digital ecosystem for the growing electric mobility industry.

The platform is designed to connect:

- 🚗 EV Drivers
- ⚡ Charging Station Operators
- 🏢 Businesses
- 🔌 EV Charging Infrastructure Providers
- 🤝 Franchise & Business Partners
- 📊 Charging Network Management Teams

The website presents EV Dock's charging solutions through an interactive and technology-focused user experience.

---

## 🛠️ Technologies Used

- **Next.js** – React framework for modern web development
- **React.js** – Component-based UI development
- **TypeScript** – Type-safe development
- **Tailwind CSS** – Responsive and modern UI styling
- **Framer Motion** – Smooth animations and interactions
- **Lucide React** – Modern icon library
- **HTML5** – Web structure
- **CSS3** – Custom styling and visual effects
